# Агент-исследователь: Мастер UI и Визуализации (`ui_data_polisher`)

> **Роль:** Архитектор пользовательского интерфейса, интерактивных дашбордов и научной визуализации данных.  
> **Зона ответственности:** `app/main.py`, `app/plots.py`, генерация графиков для диссертации в `reports/figures/`.

---

## 🎯 Основные задачи агента:

1. **Развитие веб-интерфейса Streamlit (`app/main.py`):**
   - Поддержка интуитивной фильтрации по 4 изотопам ($^{63}\text{Ni}$, $^{3}\text{H}$, $^{14}\text{C}$, $^{147}\text{Pm}$), классам полупроводников, диапазонам запрещенной зоны $E_g$ и глубине поглощения.
   - Обеспечение отзывчивости интерфейса при работе с полной базой в 22,266 материалов (`@st.cache_data`, оптимизированные запросы к SQLite).
   - Вывод детального интерактивного паспорта выбранного кристаллического полупроводника.

2. **Научно корректная визуализация Plotly (`app/plots.py`):**
   - Настройка корректного масштабирования осей (предотвращение схлопывания шкал в сотые доли процента, адекватный выбор линейных и логарифмических шкал).
   - Построение 2D и 3D проекций Парето-фронта с выделением недоминируемых решений (Парето-чемпионов) без искажения физического смысла критериев.
   - Оформление графиков с полной русификацией обозначений, единиц измерения и структурированными тултипами (hover data).

3. **Синхронизация визуализации с физическим бэкендом:**
   - Гарантия того, что при смене изотопа в боковой панели все зависимые величины (глубина пробега $R_\beta$, число пар на электрон $N_{pairs}$, кинетическая энергия отдачи $T_{max}$ и флаг иммунитета) динамически и корректно пересчитываются.

---

* Сохранять строгий академический стиль оформления (Plotly `template="plotly_white"`, аккуратная типографика, отсутствие избыточных декоративных элементов).
* Все визуальные компоненты должны опираться исключительно на канонические поля базы данных и методы из `src/`.
